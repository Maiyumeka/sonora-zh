# 公开发布许可复核

复核日期：2026-11-17。范围为本仓库公开源码、`v0.1.0-zh.1` 标签和该 Release 的 ZIP 与校验附件。本记录是对已检查材料的复核结果，不是对所有潜在第三方权利的法律保证。

## 结果

未发现上游 Sonora 的许可禁止本次源码或主程序分发。上游 MIT 全文、`Copyright (c) 2026 Px228-Da-Da`、来源链接和非官方修改说明均已保留。

公开源码与 ZIP 均未发现模型描述/权重、Python/CUDA/FFmpeg 环境、微软 CRT DLL、歌曲、音频缓存或本机日志。ZIP 只包含一个程序 `sonora-zh.exe`，以及桥接源码、文档、依赖版本清单和许可资料。Windows 系统 DLL 及 C++ 运行库由系统或使用者另行提供。

检查了 Windows Cargo 依赖图中的 207 个第三方包的许可元数据及包内声明，补齐遗漏的工作区许可，保留 Rust 标准库、Unicode 及默认嵌入字体的声明。双重许可选择可用的非 GPL 分支，累积许可要求仍然保留。读取使用者系统中文字体不等于把这些字体打包分发。

## 已更正的一处错误

初次成品附件把 `hexf-parse 0.2.1` 的许可误写成 MIT/Apache-2.0，并为它附了 Apache 文本。该包原始 `Cargo.toml.orig` 及依赖清单实际声明 **CC0-1.0**。这是一处打包声明错误；CC0 本身允许复制和再分发，并非该依赖禁止分发。

现已移除该依赖目录下错误的 Apache 文本，补充 CC0 原文，修正说明和许可文件索引，并重新生成 ZIP 校验值。主程序与功能源码未变。更正说明保存在包内 `LICENSE-CORRECTION.txt`；同名发布附件已更新，初次下载者应重新下载。
